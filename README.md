# Cozy Winter 2

Живой зимний слой поверх рабочего стола Windows 10/11: падающий снег в несколько слоёв глубины,
настоящие неровные сугробы на панели задач, ветер и намёты.

> Статус: этапы 1–2 (каркас, снег и сугробы). Остальное — в работе.

## Требования
- Windows 10/11 x64
- Node.js 20+ (LTS) — https://nodejs.org

## Команды
```
npm install          # один раз
npm start            # оверлей поверх рабочего стола (иконка-снежинка в трее)
npm start -- --windowed   # отладочное окно 1280×720 с тёмным фоном
npm start -- --verbose    # + счётчик FPS и лог рендерера в консоль
npm test             # юнит-тесты (vitest)
npm run typecheck    # проверка типов
```

## Трей
ПКМ по снежинке: Пауза, Настройки…, Режим (оверлей / окно), Земля (верх панели задач / низ экрана),
Мониторы, Присыпать снегом, Убрать весь снег, Выход. ЛКМ — настройки.

## Настройки
Хранятся в `%APPDATA%\CozyWinter2\settings.json`. Если файл повреждён, он переименовывается
в `settings.json.corrupt-…`, а приложение берёт резервную копию или значения по умолчанию.

## Скриншоты для проверки
```
npm start -- --windowed --scenario=snow60 --exit --user-data=tests/tmp-profile
```
сохранит PNG в `tests/shots/`.
