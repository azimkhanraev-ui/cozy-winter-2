# Cozy Winter 2

Живой зимний слой поверх рабочего стола Windows 10/11. Снег падает в несколько слоёв глубины и по-настоящему
копится на панели задач неровными сугробами; его можно убирать лопатой, сдувать, растапливать; из снега
катаются шары, из трёх шаров собирается снеговик. Ездит снегоуборщик, меняется время суток, стоит домик
с тёплыми окнами. Клики по рабочему столу проходят сквозь снег.

## Установка

В `release/` после сборки лежат:
- `CozyWinter2-Setup-1.0.0.exe` — установщик (без прав администратора, в профиль пользователя);
- `CozyWinter2-Portable-1.0.0.exe` — переносная версия, ничего не устанавливает.

После запуска в трее появится снежинка.

## Как пользоваться

- **Обычный режим.** Снег идёт сам, мышь работает как обычно. Шары, снеговики и док ловят мышь, только
  когда курсор над ними: шар можно взять, перетащить и бросить, снеговика — передвинуть.
- **Инструменты.** Нажмите снежинку внизу по центру (или `Ctrl+Alt+S`) — откроется док. Выбранный инструмент
  включает режим инструментов: весь экран ловит мышь, курсор показывает инструмент. Выйти — `Esc` или
  правый клик по пустому месту.
- **Снеговик.** Скатайте или поставьте три шара друг на друга: большой внизу, средний меньше, верхний ещё
  меньше, ровно. Через полсекунды неподвижности они превратятся в снеговика. Двойной клик — имя и внешность,
  правый клик — растопить.
- **Трей** (правый клик по снежинке): инструменты, пауза, настройки, режим, где «земля» (верх панели задач или
  низ экрана), мониторы, присыпать, убрать снег, встряхнуть, снимок, выход.

### Док и клавиши (в режиме инструментов)

| Клавиша | Инструмент | Клавиша | Инструмент |
|---|---|---|---|
| `1` `2` `3` `4` | шар S / M / L / XL | `R` | катать ком (растёт, собирая снег) |
| `5` | лопата (снег валиками по сторонам) | `F` | шаги |
| `6` | ластик (кисть 10–200 px) | `N` | снежный ангел |
| `7` | снегодув | `T` | ёлка |
| `8` | тепло (фен) | `B` | снежок: оттянуть и отпустить |
| `9` | насыпать снег | `D` | рулить снегоуборщиком: ←/→ (A/D), ↑ быстрее, ↓ стоп, пробел — гудок |
| `0` | рука | `Ctrl+Z` / `Ctrl+Y` | отменить / повторить (40 шагов) |

Колёсико мыши меняет размер кисти или шара. В доке также: очистить снег (порыв ветра), присыпать всё,
встряхнуть («снежный шар»), «зима за минуту» (время ×25), пауза, снимок в «Изображения\CozyWinter», настройки.

### Глобальные клавиши (меняются в настройках)

`Ctrl+Alt+S` — док / режим инструментов, `Ctrl+Alt+P` — пауза, `Ctrl+Alt+C` — очистить снег,
`Ctrl+Alt+G` — встряхнуть, `Ctrl+Alt+Q` — выход.

## Настройки

Вкладки: Снег, Земля и сугробы, Инструменты, Снеговики, Время суток (шесть фаз с редактором каждого пресета;
режимы авто/ручной/ползунок/демо), Сцена и декор (домик, ёлки, гирлянда, фонарь, забор, снегоуборщик,
звуки, снег на краях окон), Горячие клавиши, Система. Сверху — живой предпросмотр и готовые пресеты
(«Лёгкий снегопад», «Метель», «Тихий вечер», «Новогодняя ночь», «Случайный»). Экспорт/импорт настроек — во
вкладке «Система».

Настройки: `%APPDATA%\CozyWinter2\settings.json` (повреждённый файл не ломает запуск). Сцена (снег, шары,
снеговики, декор, следы) сохраняется в `%APPDATA%\CozyWinter2\scenes\` и восстанавливается при запуске.

## Системное

- Пауза при полноэкранных играх, видео и презентациях (окна скрываются).
- Режим экономии: от батареи (по умолчанию) или всегда — 30 FPS и меньше снежинок.
- Автозапуск вместе с Windows (раздел `HKCU\...\Run`, включается в настройках).
- Несколько мониторов, масштаб 100–200%.
- Если вместо прозрачного слоя чёрный экран — выключите «Аппаратное ускорение» в настройках → Система.

## Для разработчика

Нужен Node.js 20+.

```
npm install
npm start                    # оверлей поверх рабочего стола
npm start -- --windowed      # отладочное окно 1280×720 с тёмным фоном
npm start -- --verbose       # + счётчик FPS и лог рендерера
npm test                     # юнит-тесты (vitest): физика снега, инструменты, шары, снеговики, эффекты…
npm run typecheck            # проверка типов
npm run selftest             # приложение в тестовом режиме: сценарии + реальный ввод мышью, PNG в tests/shots/
npm run dist                 # установщик NSIS и portable .exe в release/
node scripts/dist.mjs --out=D:\CozyWinter2elease   # то же, но в другую папку (если на C: мало места)
npm run site                 # сайт с живым демо → website/ (открыть website/index.html)
```

## Сайт

`website/` — статическая страница (без счётчиков и трекеров) с живым демо: та же симуляция снега, шары и
снеговики, что в программе. Ссылка кнопки «Скачать» задаётся в `website/config.js` (`releasesUrl` — страница
релизов вашего репозитория GitHub); пока она пустая, кнопка ведёт к инструкции по сборке. Сайт можно выложить
на GitHub Pages или любой статический хостинг как есть.

Устройство кода:
- `src/sim/` — чистый TypeScript без DOM и Electron: снег (высотная карта, осыпание, ветер), снегопад,
  инструменты, физика шаров, снеговики, снегоуборщик, время суток, декор, эффекты. Покрыт тестами.
- `src/render/` — Canvas 2D: спрайты, сугробы, шары, снеговики, снегоуборщик, небо, декор, эффекты, иконки.
- `src/ui/` — страницы рендерера: оверлей (цикл, ввод, док, модули), окно настроек, звук (WebAudio).
- `src/main/` — Electron: окна, трей, горячие клавиши, настройки, снимки, помощник Windows API.
- `static/winhelper.cs` — помощник Windows API (полноэкранные приложения, окна для снега на краях);
  при первом запуске собирается встроенным в Windows `csc.exe` в профиль пользователя.

Принятые решения и замеры — в `DECISIONS.md`.
