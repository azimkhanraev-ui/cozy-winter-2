Кликните по снегу — появится шар.

Это та же физика и отрисовка, что и в программе: снег, сугробы, шары, снеговики. В программе всё это — прозрачным слоем на вашем экране.

Что умеет

Настоящий снег

Четыре слоя глубины, ветер с порывами, хлопья разных видов. Сугробы растут неравномерно, осыпаются по углу откоса, ветер наметает их за препятствиями.

Уборка

Лопата отбрасывает снег валиками, ластик, снегодув, фен, «насыпать», «очистить всё» порывом ветра. Отмена и повтор действий.

Снежки и снеговики

Шары с физикой: падают, катаются, их можно бросать. Ком растёт, собирая снег. Три шара друг на друге становятся снеговиком — у каждого своя шапка, шарф и имя.

Снегоуборщик

Иногда проезжает сам и расчищает снег, объезжая снеговиков. Им можно порулить стрелками и посигналить.

Время суток

Рассвет, день, закат, вечер, ночь — по часам Windows. Ночью светятся окна домика, гирлянда и фонарь, бывает северное сияние.

Не мешает работать

Клики проходят сквозь снег. Пауза при полноэкранных играх и видео, режим экономии от батареи, несколько мониторов.

Собрать самому

Нужен Node.js 20+. Исходный код — на GitHub.

git clone https://github.com/azimkhanraev-ui/cozy-winter-2.git
cd cozy-winter-2
npm install
npm start          # запустить
npm run dist       # установщик и portable .exe в release/
